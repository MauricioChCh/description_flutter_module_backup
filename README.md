# Módulo Flutter - BravIA

Este es un módulo adicional hecho en Flutter que se integra dentro de la app Android nativa para mostrar contenido específico como descripciones o información visualmente más atractiva.

Se creó específicamente para demostrar que es posible integrar módulos de un framework híbrido como **Flutter** dentro de una aplicación nativa basada en **Jetpack Compose**.

> 🔗 Este módulo forma parte de la app principal. Ver la integración en la sección de pasantías del [Frontend Android](https://github.com/MauricioChCh/frontend_bravia_backup.git).


## Características
- Construido con Flutter + Dart
- Integrado en una app Android con Jetpack Compose
