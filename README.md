# Flutter Module - BravIA

This is an additional module built with **Flutter** that integrates into the native Android app to display specific content such as descriptions or visually enhanced information.

It was created specifically to demonstrate the possibility of integrating hybrid frameworks like **Flutter** within a native app built with **Jetpack Compose**.

> 🔗 This module is part of the main app. You can see the integration in the internship section of the [Android Frontend](https://github.com/MauricioChCh/frontend_bravia_backup.git).

---

## Features
- Built with **Flutter + Dart**
- Embedded into a native Android app using **Jetpack Compose**
